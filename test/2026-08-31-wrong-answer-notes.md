## 42번 — `finally`

### 문제
오류 발생 여부와 상관없이 마지막에 실행되는 블록은 무엇인가?

- A. `try`
- B. `except`
- C. `else`
- D. `finally`

### 제출 답안
C. `else`

### 정답
D. `finally`

### 핵심 개념
예외 처리의 각 블록은 역할이 다르다.

| 블록 | 실행 시점 |
|---|---|
| `try` | 오류가 발생할 수도 있는 코드를 먼저 실행 |
| `except` | `try`에서 예외가 발생했을 때 실행 |
| `else` | `try`에서 예외가 발생하지 않았을 때 실행 |
| `finally` | 예외 발생 여부와 관계없이 마지막에 실행 |

### 암기
> `except` = 오류 O
>
> `else` = 오류 X
>
> `finally` = 오류 상관없이 항상 마지막

### 한 줄 정리
문제에서 **“오류 발생 여부와 상관없이”**, **“항상 마지막에 실행”**이라고 하면 `finally`를 고른다.
