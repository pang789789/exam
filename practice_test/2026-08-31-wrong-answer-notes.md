## 5. 시험 직전 암기 체크리스트

### Python 기본
- `input()`의 기본 반환형 → `str`
- `17 // 5` → `3`
- `17 % 5` → `2`
- `2 ** 3` → `8`
- 문자열 슬라이싱 `"Python"[1:4]` → `yth`
- 문자열은 직접 문자 대입으로 수정할 수 없음

### 자료구조
- 리스트 마지막 → `list[-1]`
- 빈 집합 → `set()`
- 딕셔너리 값 조회 → `dict[키]`
- 안전한 딕셔너리 조회 → `get()`

### 함수
- 정의 → `def`
- 입력 자리 → 매개변수(parameter)
- 결과 반환 → `return`

### 파일 / 예외
- 읽기 → `r`
- 기존 내용 뒤에 추가 → `a`
- `int("abc")` → `ValueError`
- 없는 파일 → `FileNotFoundError`
- 없는 딕셔너리 키 → `KeyError`
- 문법 오류 → `SyntaxError`
- 초기화 메서드 → `__init__()`

### AI + 설계
- AI가 만든 코드도 직접 실행하고 검증
- 목적과 범위 먼저 정리
- 하지 않을 기능도 정하기
- 데이터 모양 먼저 생각
- 작은 테스트 데이터로 예상 결과와 실제 결과 비교
- Input / Process / Output → **IPO**

## 6. 다음 시험에서의 전략

1. 다중선택은 각 보기마다 O/X를 하나씩 판단한다.
2. '맞는 것 모두'는 정답 하나를 빼먹지 않았는지 마지막에 다시 확인한다.
3. 코드 출력 문제는 대소문자·공백·숫자를 그대로 따라간다.
4. 시간이 부족하면 문제를 넘기되, 마지막에 놓친 번호를 확인한다.
5. 특히 `r / w / a`, `list[-1]`, `set()`, `get()`, `return`, `__init__()`는 즉시 떠오르게 만든다.
